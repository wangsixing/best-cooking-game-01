Sizzle & Serve — a tiny kitchen-rush cooking game. Orders land on the board with their own countdowns; grill patties and eggs, chop lettuce and tomato, and build each dish in recipe order before the timer runs out. Serve finished plates to score with a combo multiplier — a wrong ingredient breaks the combo and an expired order costs a heart. Four recipes, keyboard and mouse, offline, no build step.

## Run it

```sh
python3 -m http.server 8080 --directory game
```

Then open http://localhost:8080 in a desktop browser.
